# 🇬🇧 English

## About

This project aims to design and develop a modern, responsive and user-friendly website to showcase the association, its activities and upcoming events.

The website includes:

- 🏠 Home page
- 📰 News and events
- 👥 Meet the team
- 🎤 Classes and schedule
- 💳 Pricing and registration
- 📍 Contact information

## Technologies

- Astro
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Features

- Responsive design
- Scroll animations
- News carousel
- Smooth navigation
- Custom user interface
- Modular architecture with Astro

## Development

This project is being developed as a practical way to strengthen my web development skills while gaining hands-on experience with modern technologies such as Astro, Git and GitHub.

AI-assisted development tools are used to support implementation and learning, while all design decisions, user experience, features and project direction are defined and validated by me.

> 🚧 **This project is currently under active development.**

- CSS3

- Git
- GitHub

- Design responsive
